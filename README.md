# Mi Recorrido | Psicopedagogía

Aplicación web personal para organizar el plan de estudios, las materias y los materiales de la Licenciatura en Psicopedagogía.

## Aplicación publicada

https://mandarina2506.github.io/pagina1/

## Instalar en el celular

- **Android:** abrir el enlace en Chrome y seleccionar **Instalar aplicación** (o **Agregar a pantalla de inicio**).
- **iPhone:** abrir el enlace en Safari, tocar **Compartir** y elegir **Agregar a pantalla de inicio**.

La aplicación puede abrirse sin conexión después de haber cargado una primera vez y de que el navegador haya guardado los recursos de la PWA.

## Datos y privacidad

Las materias, los resúmenes y los archivos se guardan en el almacenamiento del navegador del dispositivo que se esté usando. No hay sincronización entre el celular y la computadora. Para mover información entre dispositivos, usar **Exportar respaldo** en un dispositivo y **Importar respaldo** en el otro.

El repositorio es público porque GitHub Pages está publicado desde este proyecto. No subir a este repositorio apuntes personales, documentos privados ni información sensible.

## Publicación

GitHub Actions publica el sitio automáticamente cuando se actualiza la rama `main`. El flujo está en `.github/workflows/pages.yml`.

Los archivos `deploy-source/part-*.txt` son fragmentos del paquete de publicación que el flujo reconstruye. No editarlos ni eliminarlos de forma individual.

## Plan de estudios

El plan de estudios queda editable desde la aplicación. No se precargó una currícula institucional porque las materias pueden variar según la universidad.
